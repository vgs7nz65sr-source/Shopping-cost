# Shopping Cost Analyzer

An installable iPhone-style Progressive Web App for storing, parsing and analysing weekly shopping costs.

## GitHub Pages deployment

1. Create a GitHub repository (for example `shopping-cost-analyzer`).
2. Upload all files in this folder to the repository's `main` branch, preserving the `.github/workflows/pages.yml` file.
3. In **Settings → Pages**, set **Source** to **GitHub Actions**.
4. Push/commit the files. The included workflow deploys the site automatically.
5. Open the resulting GitHub Pages URL in Safari on iPhone.
6. Use **Share → Add to Home Screen** to install it.

The app stores weekly data locally in the browser/device. The GitHub repository hosts the app files; it does not contain your saved shopping history unless you explicitly add data files to the repository.
